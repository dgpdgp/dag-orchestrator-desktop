Папка назначения для установки: D:\DAG\INSTALL

1. Распакуйте ВСЁ содержимое архива в D:\DAG\INSTALL.
2. Убедитесь, что установлен Claude Desktop и вы хотя бы раз его открывали.
3. Полностью завершите Claude Desktop (значок около часов -> Quit/Выход).
4. Дважды нажмите CHECK-FIRST.bat — программа только проверит комплект.
5. Дважды нажмите INSTALL-DAG.bat — программа установит MCP для Claude Chat.
6. После сообщения INSTALL OK дважды нажмите VERIFY-DAG.bat.
7. Откройте Claude Desktop заново. Настройки -> Разработчик:
   сервер dag-orchestrator-desktop должен показывать «Выполняется».
8. Для Cowork: Плагины -> Добавить -> Загрузить плагин.
   Выберите файл DAG-Orchestrator-CLAUDE-PLUGIN-ready.zip
   в этой папке D:\DAG\INSTALL. (Он создаётся установщиком.)

НЕТ PYTHON? Программа объяснит, где установить Python 3.10 или новее.
Не нужен администратор Windows. Установщик НЕ устанавливает Python сам.

УДАЛЕНИЕ: UNINSTALL-DAG.bat; затем удалите плагин из Claude вручную.
Графы DAG по умолчанию НЕ удаляются при удалении MCP.

Если команда в окне пишет ERROR, запишите её или сделайте скриншот.
Как использовать Claude: см. разделы 4 и 5 в INSTALLATION_GUIDE_RU.md.
Команда Skill сохранена: /dag-orchestrator-desktop (если доступна в интерфейсе).
