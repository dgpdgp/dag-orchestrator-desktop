# Проверки установщика v2.3.0

**Разработчик:** Давид Пагава / David Pagava (© 2026 David Pagava)

Цель: воспроизводимый пакет установки без потери других MCP-настроек.

## Проверка исходного кода
- Загружен сервер `mcp/server.py` из финально проверенного DAG Orchestrator v2.3.0.
- Готовая структура Claude Plugin содержит `.claude-plugin/plugin.json`, `.mcp.json`, Skill, три субагента и сервер.
- Перед установкой проверяются SHA-256 файлов комплекта и живой протокольный MCP smoke-test на временном хранилище.

## Автоматизированные испытания движка (изолированная среда)
1. Smoke-test локального MCP.
2. Сохранение других серверов и настроек при установке.
3. Повторная установка и резервные копии.
4. Удаление только своей записи.
5. Защита при конфликте имени чужого сервера.
6. Отказ при повреждённом JSON.
7. Отказ при JSON не-объекте.
8. Отказ при дублированных ключах JSON.
9. Сборка Plugin ZIP, проверка обязательных путей и команды Python.
10. Выбор активной MSIX-конфигурации при наличии старой.
11. Безопасный отказ при нескольких конфигурациях без активного идентификатора.
12. Режим классического Claude.
13. JSON с UTF-8 BOM.
14. Обнаружение отсутствующего установленного server.py.
15. Отсутствие изменений посторонних файлов.
16. Обнаружение неверной установленной команды/пути.

Эти тесты выполняются через Python в изолированной среде, **не** на пользовательском компьютере Windows 11. Следующий этап — реальный запуск BAT на отдельном Windows 11 и проверка Claude Desktop.

## Критерий готовности на втором Windows 11
- `CHECK OK` до установки.
- `INSTALL OK` + создана резервная копия.
- `VERIFY OK` + MCP отвечает.
- В Claude Desktop → Разработчик наш сервер `Running`.
- После импорта сформированного ZIP доступны Skill, MCP и три субагента.
- Один учебный граф A→(B,C)→D выполнился с правильным порядком и с реальными инструментами.
